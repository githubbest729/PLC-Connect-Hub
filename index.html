PLC-Connect Hub

How to use
  1. Choose the PLC brand and type an address such as DB1.DBD4, M10.0, N7:0 or Motor1.Speed.
  2. For analog values, set the raw and engineering ranges (Siemens analog default is 0 to 27648).
  3. Press Convert, then press Copy beside any result.
  4. For many tags use Bulk CSV below: import a file or paste rows, convert, then export the result.

Bulk CSV

How to use

Columns: brand (s7 or ab), address, type (optional), rawMin, rawMax, engMin, engMax. Empty range cells use 0, 27648, 0, 100. Press Template to see an example.

Modbus register calculator

How to use

Enter a register like 40001 (holding), 30001 (input register), 00001 (coil) or 10001 (discrete input). Five- and six-digit numbers are read as prefix plus address. For a plain number choose the function code and numbering. The PDU offset is what goes on the wire.

Connection quick-copy

How to use

Write or paste a SQL query or QuickScript, then press Format to tidy it or Minify to compact it. Save snippet stores it on this device. Use Edit to reload a snippet and Copy to put it on the clipboard. Tab inserts two spaces.
